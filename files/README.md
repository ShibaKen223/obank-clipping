# 每日新聞剪報自動化

把公關科每天寄來的「榮董新聞」信件，自動整理成 Word 剪報草稿。
原本全手工要 40–70 分鐘，現在跑程式約 3 分鐘 + 人工校對。

**產出是草稿。程式絕對不會寄信，校對完請自己寄。**

---

## 〇、Mac 桌面工具（日常就用這個）

下面第一、二節是指令列用法（辦公室 Windows 機器用）。
在 Mac 上已經包成桌面 app，日常操作只有兩步：

### 安裝（只要做一次）

```bash
./tools/build_app.sh
```

桌面會出現「**每日剪報**」。第一次執行時系統會問要不要允許它控制「終端機」，
按允許 —— 需要終端機是為了讓你看得到 3 分鐘的進度和最後的摘要。

### 每天

1. 把當天的「MMDD_榮董新聞」信件另存成 `.eml` 放進「**下載**」資料夾
2. 雙擊桌面的「**每日剪報**」

它會自動挑下載資料夾裡最新的一封榮董新聞、跑完整流程、
把成品用 Word 開起來。想指定某一封的話，把那個 `.eml` 直接拖到 app 圖示上。

兩個 `.docx` 附件不用自己存，程式會從信件裡拆。
第一次執行會多花約 1 分鐘自動建 Python 環境，之後就不會了。

**跑完一定要看終端機視窗最後的摘要**，它會告訴你哪幾則失敗、
哪幾張圖要手動補。看完按 Enter 關掉。

搬動專案資料夾之後，重跑一次 `./tools/build_app.sh` 就好。

## 一、安裝（只要做一次）

### 1. 確認 Python 叫得到

這台機器上 `python` 是 Microsoft Store 的空殼，**執行任何東西都不會有反應也不會報錯**，
一律用 `py`：

```bash
py --version
```

看到 `Python 3.12.8` 就對了。如果連 `py` 都沒有，去 python.org 裝一個。

### 2. 裝套件

```bash
py -m pip install requests beautifulsoup4 trafilatura python-docx Pillow
```

| 套件 | 用途 |
|---|---|
| `requests` | 抓網頁 |
| `beautifulsoup4` | 找 og:image、記者署名 |
| `trafilatura` | 抽新聞內文 |
| `python-docx` | 讀寫 Word |
| `Pillow` | 修正部分網站的圖片格式（沒有它壹蘋的圖插不進去）|

## 二、每天的操作

### 1. 把信件存成 .eml

在 Outlook / Gmail 把當天的「MMDD_榮董新聞」信件另存成 `.eml`，
放到這個資料夾。**兩個 .docx 附件不用自己存**，程式會拆。

### 2. 跑一行指令

```bash
py main.py 0804_榮董新聞.eml
```

約 2–3 分鐘（27 則網址，每則之間會停 1.5 秒，這是刻意的，不要拿掉）。

跑完會看到摘要：

```
完成：outputs\20260804 每日新聞剪報.docx
  成功    29 則（集團新聞 2 / 金融同業新聞 8 / ...）
  待補圖  0 則
  失敗    0 則
```

### 3. 開 Word 做三件事

1. **填封面目錄的頁碼** — 現在是 `P.__~__`，頁碼要 Word 排完版才知道，程式算不出來
2. **搜尋紅字「圖片待補」** — 如果摘要說有待補圖，那幾處要手動貼圖
3. **校對後自己寄出**

## 三、其他用法

```bash
# 只重產 Word，不重新抓網頁（改完版面設定想重跑時用，省 2 分鐘也不打擾對方伺服器）
py main.py 0804_榮董新聞.eml --skip-fetch

# 手動指定附件路徑（信件裡附件檔名跟平常不一樣時）
py main.py 0804_榮董新聞.eml --excerpt "摘錄.docx" --template "前一天.docx"

# 只想看信件解析對不對，不產 Word
py parse_email.py 0804_榮董新聞.eml --json urls.json

# 只想看新聞抓得到抓不到（診斷用，不產 Word）
py test_fetch.py urls.json

# 只想看集團新聞抽得對不對
py group_news.py "20260804 王道銀行集團相關新聞報導摘錄.docx" --picks 1,3
```

## 四、常見狀況排除

### 指令按下去完全沒反應，直接跳回提示字元

你打成 `python` 了。改用 `py`。

### 「在附件裡找不到集團新聞摘錄檔」

程式靠檔名認附件：含「摘錄」的是集團新聞來源，含「每日新聞剪報」的是底稿。
如果公關科改了檔名，用 `--excerpt` 和 `--template` 手動指定。

### 某則新聞 FAIL

摘要的「失敗」清單會列出網址和原因。**那幾則不會出現在 Word 裡**，要手動補。
最可能的原因是那個網域沒支援 —— 目前只認得這六個：

```
money.udn.com / udn.com          → 聯合報系
www.ctee.com.tw / www.chinatimes.com → 中時集團
ec.ltn.com.tw                    → 自由時報
news.nextapple.com               → 壹蘋新聞網
```

冒出新媒體時，程式會印 `UNSUPPORTED 未支援的網域：xxx`。
要加的話在 `extractors.py` 裡照著現有的 adapter 加一個，通常只要改
`parse_media` / `parse_date` / `parse_reporter` 三個方法。

### 有則新聞的媒體或記者是空的 / 怪怪的

`extract_review.txt` 會列出每則抽到的五個欄位，開來看是哪一則。
各站的規則寫在 `extractors.py` 各個 adapter 的註解裡。

已知會踩的坑（都已經處理，但改程式時不要弄壞）：

- **ctee 每頁有兩個 `og:image`，第二個是工商時報的 logo**。取錯的話每則 ctee
  都會被插一張 logo 當新聞照，而且不會報錯。程式用「只取第一個」+ 黑名單兩道防線擋。
- **中央社供稿的署名是「中央社 記者張謙香港3日電」**，姓名後面直接黏地點沒有分隔符，
  要靠地點清單才切得乾淨。地點清單在 `extractors.py` 的 `CNA_PLACES`。
- **udn.com 的 `og:site_name` 一律是「聯合新聞網」**，但底下同時放經濟日報和聯合報的稿，
  要看署名開頭那個報名才準。
- **「本報訊」不是人名**，是沒署名的意思，會自動換成「新聞中心」。

### 產出的 Word 看起來跟平常不一樣

程式是拿**前一天的成品當底稿**，清掉內容再填新的。
黑底白字、表格的黑底白框線、兩個自訂樣式（榮董新聞內文 / 榮董資訊）都靠底稿繼承。

所以**底稿一定要是正常的成品檔**。如果哪天底稿本身版面被改壞了，產出就會跟著壞。
真的出問題時，換一份更早、確定正常的成品當底稿：

```bash
py main.py 0804_榮董新聞.eml --template "0730 每日新聞剪報.docx"
```

### 集團新聞抓錯篇

信裡的「第N則」對應的是**摘錄檔目錄的編號**，也就是文章數。
注意目錄上有些項目寫「並轉載於 A、B、C」——那是**一篇文章、多次報導**，
編號只算一個。程式會拿檔案裡的「文章總數：N」跟實際解析的篇數對帳，對不上會警告。

## 五、檔案說明

| 檔案 | 做什麼 |
|---|---|
| `main.py` | **每天跑這個**，串起下面全部 |
| `parse_email.py` | 解析 .eml → `urls.json` + 拆附件到 `attachments/` |
| `extractors.py` | 抓網路新聞內文與圖 → `extract_result.json` |
| `group_news.py` | 從摘錄 .docx 取出「第N則」集團新聞 |
| `build_docx.py` | 產出 Word（以前一天成品為底稿）|
| `test_fetch.py` | 診斷用：測哪些網域抓得到，不產 Word |
| `../tools/run_clipping.sh` | Mac 桌面工具的實際內容：顧環境、找信件、開成品 |
| `../tools/build_app.sh` | 產生桌面上的「每日剪報」，只有安裝或搬家時要跑 |

跑完會產生這些中間檔，可以直接刪，下次會重生：

```
urls.json              信件解析結果
extract_result.json    抓到的 27 則內容（--skip-fetch 會讀這個）
extract_review.txt     人工校對用的欄位清單
group_images/          從摘錄 .docx 拆出來的圖
attachments/           從信件拆出來的兩個 .docx
outputs/               產出的剪報
```

## 六、不要改的地方

1. **`extractors.py` 的 `POLITE_DELAY = 1.5`** — 每則之間停 1.5 秒。
   被對方封 IP 的代價遠大於省下的 40 秒。
2. **不要加自動寄信。** 產出草稿即停是刻意的。
3. **不要把信件或附件上傳到任何外部服務。** 全流程本機執行，
   對外連線只有公開新聞網站。信件標註「機密／內部限閱」。
4. **失敗要看得見。** 任何抽取失敗都會在終端機列出，Word 裡以紅字標位置。
   不要為了讓畫面好看而把錯誤吞掉。

---

## 七、已知限制

- **封面目錄頁碼要手填。** 頁碼得等 Word 實際排版才知道，程式算不出來。
- **每則最多一張圖。** 原文有多張時只取第一張（跟以往的剪報一致）。
- **日期用新聞發布日**，不是信件寄出日。所以會看到 8/4 的信裡有 8/3 的新聞。
  要改成一律填當天的話，改 `extractors.py` 的 `parse_date`。
- **通訊社供稿的媒體欄填刊登的報紙**（例如中央社供稿、經濟日報刊登 → 填經濟日報）。
  要改體例的話，改 `extractors.py` 最上面的 `MEDIA_OVERRIDES` 附近。
