# 每日新聞剪報自動化

把公關科每天寄來的「榮董新聞」信件，自動整理成 Word 剪報草稿。
原本全手工要 40–70 分鐘，現在跑程式約 3 分鐘 + 人工校對。

**產出是草稿。程式絕對不會寄信，校對完請自己寄。**

> 只是要把工具裝起來用的話，看 [`../INSTALL.md`](../INSTALL.md) 就夠了。
> 這份是完整說明，含診斷、程式判斷規則、改程式時不要弄壞的地方。

---

## 〇、日常怎麼用（Windows 與 Mac）

桌面工具兩個平台各有一套，**日常操作完全一樣**。
下面第一、二節是指令列用法，出狀況要診斷時才需要。

### 安裝（每台機器只做一次）

**Windows** —— 在專案資料夾開 PowerShell：

```bash
powershell -ExecutionPolicy Bypass -File .\tools\build_app.ps1
```

**Mac** —— 在專案資料夾開終端機：

```bash
./tools/build_app.sh
```

兩邊都會在桌面放一個「**每日剪報**」。
Mac 第一次執行時系統會問要不要允許它控制「終端機」，按允許 ——
需要終端機是為了讓你看得到 3 分鐘的進度和最後的摘要。

搬動專案資料夾之後，重跑一次 `build_app.ps1` / `build_app.sh` 就好。

### 每天兩步

1. 在 Outlook / Gmail 把當天的「MMDD_榮董新聞」信件**另存成 `.eml`**，丟進「**下載**」資料夾
2. **雙擊桌面的「每日剪報」**

**只丟檔案不會自動開始跑**，一定要雙擊圖示 —— 它不是監看資料夾的背景程式，
是你按了才動。想指定某一封（不是最新那封）的話，把那個 `.eml` **拖到圖示上**。

兩個 `.docx` 附件不用自己存，程式會從信件裡拆。
第一次執行會多花約 1 分鐘自動建 Python 環境，之後就不會了。

自動挑信件是靠**檔名含「榮董新聞」**去找下載資料夾裡最新的一封。
另存時檔名被改掉也沒關係，會跳出選檔視窗讓你自己挑。

### 跑完一定要看視窗最後的摘要

```
完成：outputs/20260804 每日新聞剪報.docx
  成功    29 則（集團新聞 2 / 金融同業新聞 8 / ...）
  待補圖  0 則
  失敗    0 則

  接下來要人工做的:
    1. 校對後自行寄出（本程式不會寄信）
```

「接下來要人工做的」列什麼就做什麼，通常是這幾項：

| 出現時 | 做什麼 |
|---|---|
| 待補圖 > 0 | 在 Word 裡搜尋紅字「**圖片待補**」，手動貼圖 |
| 失敗 > 0 | 那幾則**不在 Word 裡**，要自己補。摘要會列出網址和原因 |
| 說要填頁碼 | 只有這台沒 Word 時才會出現，封面維持 `P.__~__` 自己填 |
| 每次 | **校對後自己寄出**（程式不會寄信）|

摘要裡的「已標記 18 處（王道銀行 13 / 王道 4 / …）」是給你對數字用的。
內文提到「王道銀行」「O-Bank」和董事長姓名的地方會自動標成粗體＋紅色粗底線，
不用自己標。單獨的「王道」只在**集團新聞**那一段標，其他類別不標，見§七。

成品會自動用 Word 開起來，檔案在 `files/outputs/`。看完摘要按 Enter 關掉視窗。

### 兩個平台唯一的差別

只有一處，而且操作上察覺不到：封面目錄的頁碼，Windows 是用 COM 直接問 Word
「這一段排在第幾頁」，Mac 是叫 Word 匯出 PDF 再數。結果一樣。
細節見§七第一項。

## 一、安裝（只要做一次）

### 1. 確認 Python 叫得到

這台機器上 `python` 是 Microsoft Store 的空殼，**執行任何東西都不會有反應也不會報錯**，
一律用 `py`：

```bash
py --version
```

看到 `Python 3.12.8` 就對了。如果連 `py` 都沒有，去 python.org 裝一個。

### 2. 裝套件

```bash
py -m pip install -r ../requirements.txt
```

| 套件 | 用途 |
|---|---|
| `requests` | 抓網頁 |
| `beautifulsoup4` | 找 og:image、記者署名 |
| `trafilatura` | 抽新聞內文 |
| `python-docx` | 讀寫 Word |
| `Pillow` | 修正部分網站的圖片格式（沒有它壹蘋的圖插不進去）|
| `pywin32` | 只在 Windows 裝：問 Word 每段排在第幾頁，用來填封面頁碼 |
| `pypdfium2` | 只在 Mac 裝：讀 Word 匯出的 PDF 數頁碼，同上 |

## 二、每天的操作

### 1. 把信件存成 .eml

在 Outlook / Gmail 把當天的「MMDD_榮董新聞」信件另存成 `.eml`，
放到這個資料夾。**兩個 .docx 附件不用自己存**，程式會拆。

### 2. 跑一行指令

```bash
py main.py 0804_榮董新聞.eml
```

約 2–3 分鐘（27 則網址，每則之間會停 1.5 秒，這是刻意的，不要拿掉）。

跑完會看到摘要：

```
完成：outputs\20260804 每日新聞剪報.docx
  成功    29 則（集團新聞 2 / 金融同業新聞 8 / ...）
  待補圖  0 則
  失敗    0 則
```

### 3. 開 Word 做這幾件事

摘要最後的「接下來要人工做的」會列出當次真正要處理的，照著做就好。可能會出現：

1. **填封面目錄的頁碼** — 只有在這台沒 Word、頁碼算不出來時才會出現（維持 `P.__~__`）
2. **搜尋紅字「圖片待補」** — 如果摘要說有待補圖，那幾處要手動貼圖
3. **校對後自己寄出**

## 三、其他用法

```bash
# 只重產 Word，不重新抓網頁（改完版面設定想重跑時用，省 2 分鐘也不打擾對方伺服器）
py main.py 0804_榮董新聞.eml --skip-fetch

# 手動指定附件路徑（信件裡附件檔名跟平常不一樣時）
py main.py 0804_榮董新聞.eml --excerpt "摘錄.docx" --template "前一天.docx"

# 只想看信件解析對不對，不產 Word
py parse_email.py 0804_榮董新聞.eml --json urls.json

# 只想看新聞抓得到抓不到（診斷用，不產 Word）
py test_fetch.py urls.json

# 只想看集團新聞抽得對不對
py group_news.py "20260804 王道銀行集團相關新聞報導摘錄.docx" --picks 1,3
```

## 四、常見狀況排除

### 指令按下去完全沒反應，直接跳回提示字元

你打成 `python` 了。改用 `py`。

### 「存不進 outputs\...docx，檔案正被別的程式鎖住」

上一版還開在 Word 裡。Windows 的 Word 會把開著的檔案鎖成獨佔，存不進去。
關掉那個 Word 視窗再跑一次就好；用桌面捷徑跑的話會自動先幫你關，
只有直接下 `py main.py` 才會遇到。加 `--skip-fetch` 重跑就不用再抓一次網頁。

### Windows：「因為這個系統上已停用指令碼執行」

PowerShell 預設不跑沒簽章的 `.ps1`。桌面捷徑本身帶了 `-ExecutionPolicy Bypass`
所以不會遇到，只有手動跑 `build_app.ps1` 時要照著§〇 那行的寫法加上這個參數。
不需要去改系統的執行原則。

### 「在附件裡找不到集團新聞摘錄檔」

程式靠檔名認附件：含「摘錄」的是集團新聞來源，含「每日新聞剪報」的是底稿。
如果公關科改了檔名，用 `--excerpt` 和 `--template` 手動指定。

### 某則新聞 FAIL

摘要的「失敗」清單會列出網址和原因。**那幾則不會出現在 Word 裡**，要手動補。
最可能的原因是那個網域沒支援 —— 目前只認得這六個：

```
money.udn.com / udn.com          → 聯合報系
www.ctee.com.tw / www.chinatimes.com → 中時集團
ec.ltn.com.tw                    → 自由時報
news.nextapple.com               → 壹蘋新聞網
```

冒出新媒體時，程式會印 `UNSUPPORTED 未支援的網域：xxx`。
要加的話在 `extractors.py` 裡照著現有的 adapter 加一個，通常只要改
`parse_media` / `parse_date` / `parse_reporter` 三個方法。

### 有則新聞的媒體或記者是空的 / 怪怪的

`extract_review.txt` 會列出每則抽到的五個欄位，開來看是哪一則。
各站的規則寫在 `extractors.py` 各個 adapter 的註解裡。

已知會踩的坑（都已經處理，但改程式時不要弄壞）：

- **ctee 每頁有兩個 `og:image`，第二個是工商時報的 logo**。取錯的話每則 ctee
  都會被插一張 logo 當新聞照，而且不會報錯。程式用「只取第一個」+ 黑名單兩道防線擋。
- **中央社供稿的署名是「中央社 記者張謙香港3日電」**，姓名後面直接黏地點沒有分隔符，
  要靠地點清單才切得乾淨。地點清單在 `extractors.py` 的 `CNA_PLACES`。
- **udn.com 的 `og:site_name` 一律是「聯合新聞網」**，但底下同時放經濟日報和聯合報的稿，
  要看署名開頭那個報名才準。
- **「本報訊」不是人名**，是沒署名的意思，會自動換成「新聞中心」。

### 產出的 Word 看起來跟平常不一樣

程式是拿**前一天的成品當底稿**，清掉內容再填新的。
黑底白字、表格的黑底白框線、兩個自訂樣式（榮董新聞內文 / 榮董資訊）都靠底稿繼承。

所以**底稿一定要是正常的成品檔**。如果哪天底稿本身版面被改壞了，產出就會跟著壞。
真的出問題時，換一份更早、確定正常的成品當底稿：

```bash
py main.py 0804_榮董新聞.eml --template "0730 每日新聞剪報.docx"
```

### 集團新聞抓錯篇

信裡的「第N則」對應的是**摘錄檔目錄的編號**，也就是文章數。
注意目錄上有些項目寫「並轉載於 A、B、C」——那是**一篇文章、多次報導**，
編號只算一個。程式會拿檔案裡的「文章總數：N」跟實際解析的篇數對帳，對不上會警告。

## 五、檔案說明

| 檔案 | 做什麼 |
|---|---|
| `main.py` | **每天跑這個**，串起下面全部 |
| `parse_email.py` | 解析 .eml → `urls.json` + 拆附件到 `attachments/` |
| `extractors.py` | 抓網路新聞內文與圖 → `extract_result.json` |
| `group_news.py` | 從摘錄 .docx 取出「第N則」集團新聞 |
| `build_docx.py` | 產出 Word（以前一天成品為底稿）|
| `paginate.py` | 請 Word 排版一次，算出封面目錄的頁碼（Windows 走 COM／Mac 走 PDF）|
| `test_fetch.py` | 診斷用：測哪些網域抓得到，不產 Word |
| `../tools/run_clipping.ps1` | **Windows** 桌面工具的實際內容：顧環境、找信件、開成品 |
| `../tools/build_app.ps1` | **Windows** 產生桌面上的「每日剪報」，只有安裝或搬家時要跑 |
| `../tools/run_clipping.sh` | **Mac** 同 `run_clipping.ps1` |
| `../tools/build_app.sh` | **Mac** 同 `build_app.ps1` |

`tools/` 底下 Windows 與 Mac 是兩份對照的腳本，改行為時**兩邊要一起改**。

跑完會產生這些中間檔，可以直接刪，下次會重生：

```
urls.json              信件解析結果
extract_result.json    抓到的 27 則內容（--skip-fetch 會讀這個）
extract_review.txt     人工校對用的欄位清單
group_images/          從摘錄 .docx 拆出來的圖
attachments/           從信件拆出來的兩個 .docx
outputs/               產出的剪報
```

## 六、不要改的地方

1. **`extractors.py` 的 `POLITE_DELAY = 1.5`** — 每則之間停 1.5 秒。
   被對方封 IP 的代價遠大於省下的 40 秒。
2. **不要加自動寄信。** 產出草稿即停是刻意的。
3. **不要把信件或附件上傳到任何外部服務。** 全流程本機執行，
   對外連線只有公開新聞網站。信件標註「機密／內部限閱」。
4. **失敗要看得見。** 任何抽取失敗都會在終端機列出，Word 裡以紅字標位置。
   不要為了讓畫面好看而把錯誤吞掉。

## 七、已知限制

- **封面目錄頁碼要有 Word 才填得了。** 頁碼得等實際排版才知道，所以是把成品
  丟給 Word 排一次再數出來的。Windows 用 COM 直接問 Word「這一段在第幾頁」，
  Mac 沒有等價介面（Word for Mac 的 AppleScript 字典裡沒有這個），只好改成
  匯出 PDF 再從 PDF 數。兩條路都走不通時會跳過，維持 `P.__~__` 讓人工填。
- **標記規則分兩段，集團新聞標得比較寬。** 內文出現這些字時會自動套上
  樣式「榮董新聞醒目 字元」（粗體＋紅色粗底線）：

  | | 集團新聞 | 其他六個類別 |
  |---|---|---|
  | 王道銀行（O-Bank）、王道銀行、O-Bank | 標 | 標 |
  | 駱錦明、駱怡君 | 標 | 標 |
  | 單獨的**王道**（王道薪轉戶、王道簽帳金融卡…）| 標 | **不標** |

  「王道」分開處理是因為它同時是常用詞（「分散投資才是王道」）。集團新聞是
  從摘錄檔來的自家報導，那裡的「王道○○」確實都是自家的東西；其他類別是一般
  財經新聞，全篇標會誤傷。

  「董事長」「榮譽董事長」兩邊都不標，只標姓名 —— 財經新聞裡別家公司的董事長
  滿天飛（0804 那天光國票金、中鋼、富邦投顧就十幾處）。

  換董事長或想調整規則，改 `build_docx.py` 最上面的 `CHAIRMAN_NAMES`、
  `HIGHLIGHT_TERMS`（全篇通用）、`GROUP_ONLY_TERMS`（只有集團新聞），
  不用動下面的程式。
  標記只發生在**內文**，標題不標（人工版的標題也沒標）。
- **udn 沒配圖的稿子**，og:image 會給網站 logo（紅色「經濟日報」字樣），
  已在 `IMAGE_BLACKLIST` 擋掉 `/static/`。那些新聞本來就沒照片，剪報裡就沒圖。
- **只有工商時報（ctee）分得出資料圖表與情境照**，因為它的圖檔名有
  `_Table_` / `_PictureItem_`。其他媒體沒有這種標示，抓到沒資訊量的照片
  只能手動換。
- **每則最多一張圖。** 原文有多張時只取第一張（跟以往的剪報一致）。
- **日期用新聞發布日**，不是信件寄出日。所以會看到 8/4 的信裡有 8/3 的新聞。
  要改成一律填當天的話，改 `extractors.py` 的 `parse_date`。
- **通訊社供稿的媒體欄填刊登的報紙**（例如中央社供稿、經濟日報刊登 → 填經濟日報）。
  要改體例的話，改 `extractors.py` 最上面的 `MEDIA_OVERRIDES` 附近。
