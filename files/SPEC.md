# 每日新聞剪報自動化 — 開發規格

## 這份文件怎麼用

把整份貼進 Claude Code 當第一則訊息，或存成 repo 根目錄的 `SPEC.md`
後告訴 Claude Code「讀 SPEC.md，我們從 Phase 1 開始」。

---

## 1. 背景

我在王道銀行（O-Bank）企業溝通部實習。每天早上約 10:20 收到公關科同事
寄來的「榮董新聞」信件，我要把信裡指定的新聞整理成一份 Word 剪報，
當天回寄。目前全手工，每天約 40–70 分鐘。

**目標：把它壓到 10 分鐘以內（產草稿 + 人工校對）。**

我的技術背景：Python 中等，用過 Claude Code、Git、寫過 CLI 工具。
不是專職工程師，程式要好讀、好維護、註解用繁體中文。

---

## 2. 輸入：每日信件

寄件者固定為公關科同事，主旨格式 `MMDD_榮董新聞`，收件到我的 Gmail。

### 2.1 信件正文結構（純文字版）

Outlook 的編號清單在純文字版會全部渲染成 `  1.  類別名`：

```
  1.  集團新聞
第1,3則

  1.  金融同業

市場震盪 資金何處去？LINE Bank 口袋帳戶活存1.5%限額提高至3,000萬元
https://money.udn.com/money/story/5613/9667796?from=edn_newestlist_rank

澳洲央行總裁放鷹！國銀推新一波「澳幣」定存 年利率上看10%
https://udn.com/news/story/7239/9667340?from=udn-catelistnews_ch2
...

  1.  主管機關與金融
...
```

固定 6 個類別，順序固定：

1. 集團新聞（**沒有網址**，只有「第N則」指示）
2. 金融同業
3. 主管機關與金融
4. 其他政府機關及經濟新聞
5. 產業新聞
6. 大陸新聞
7. 國際新聞

信尾遇到 `Best Regards` / 分隔線就停止解析。

### 2.2 附件（2 個 .docx）

| 附件 | 用途 |
|---|---|
| `YYYYMMDD 王道銀行集團相關新聞報導摘錄.docx` | 媒體監測廠商產出。**集團新聞的來源**，內含編號目錄與全文 |
| `YYYYMMDD 每日新聞剪報.docx` | 前一天的成品。**當作排版 template 用** |

摘錄檔結構（可靠、好解析）：

```
2026/08/04王道銀行集團相關新聞報導摘錄
文章總數：7

1.  標題 (媒體)    2
2.  標題 (媒體)    4
...

新聞內文：

標題 (媒體)
媒體 2026/08/04 記者蔡穎青報導
字數：761 words 面積：210.7 cm2 廣告價值：NT42,306
（內文段落…）
```

信裡的「第1,3則」對應目錄編號，取出第 1 則與第 3 則的完整內容。

## 3. 已驗證的事實（不要重新推導）

用 2026/08/04 那封信實測：

- 網址共 **27 則**，只來自 **4 個媒體集團**：

  | 網域 | 則數 |
  |---|---|
  | `money.udn.com` | 10 |
  | `www.ctee.com.tw` | 10 |
  | `www.chinatimes.com` | 3 |
  | `udn.com` | 2 |
  | `ec.ltn.com.tw` | 1 |
  | `news.nextapple.com` | 1 |

  → **只需要 4 組抽取規則**（聯合報系、中時系、自由、壹蘋），不是 27 組。

- 前一天成品含 **29 個表格**，剛好等於 27 則網址 + 2 則集團新聞。
  每則新聞一個表格，結構完全公式化。

- 全篇 **19 張圖 / 29 則**，約 6 成有配圖，其餘沒有。

## 4. 輸出：Word 剪報規格（已從實檔量測）

### 4.1 版面

- 紙張 **A3 直式**：11.69 × 16.54 in
- 文字欄寬 **10.12 in**
- 文件內含自訂段落樣式 **「榮董新聞內文」** ← 直接沿用，不要自己造樣式

### 4.2 每則新聞的區塊（固定順序）

```
① 表格：3 列 × 1 欄，欄寬 2.156 in，字級 16pt
     第1列 = 媒體名稱（例：經濟日報）
     第2列 = 日期，格式 YYYY.MM.DD（例：2026.08.04）
     第3列 = 記者姓名（無署名時填「新聞中心」）

② 標題：樣式「榮董新聞內文」，置中，24pt，粗體

③ 圖片（若有）：置中，寬度 = min(原圖寬, 10.12 in)，維持長寬比

④ 內文：樣式「榮董新聞內文」，靠左，18pt，逐段落
```

注意：圖片位置在**標題之後、內文之前**，每則最多一張。

### 4.3 首頁目錄

文件最前面是頁碼索引，需依實際頁數回填：

```
集團新聞                 P.1~4
金融同業新聞             P.4~15
主管機關與金融政策       P.16~23
其他政府機關及經濟新聞   P.24~31
產業新聞                 P.32~37
大陸新聞                 P.38~44
國際新聞                 P.45~51
```

這是最後才做的步驟（要等前面內容定案）。若自動計算頁碼太困難，
改用 Word 原生 TOC 功能或留空讓我手填，不要為此卡住。

## 5. 現有程式碼

repo 已有兩支可用的腳本，**不要重寫，在此基礎上擴充**：

- `parse_email.py` — 解析 .eml，輸出 `urls.json`（含 `group_news_picks`），
  附件自動存到 `attachments/`。已驗證可正確解析 27 則。
- `test_fetch.py` — 反爬診斷腳本，逐則測試 HTTP 狀態、內文字數、
  `og:image` 可用性，並依網域彙總。

## 6. 開發階段與驗收條件

### Phase 0：反爬實測（我自己跑，非你的工作）

執行 `python test_fetch.py urls.json`，把結果貼給你。
**在看到結果之前，不要開始寫抽取器。** 結果決定架構：

- 全部 OK → 全自動
- 中時系被擋 → 該網域改走 Claude in Chrome 半自動，其餘全自動
- 過半被擋 → 整體退回半自動，重新設計

### Phase 1：內文抽取器 `extractors.py`

- 每個媒體集團一個 adapter，統一回傳
  `{media, date, reporter, title, body_paragraphs[], image_url}`
- `og:image` 抓主圖；抓圖時**必須帶 `Referer` header**（防盜連）
- 抓不到圖 → `image_url = None`，不要報錯
- 每則之間 `sleep(1.5)`，不要拿掉
- **驗收**：27 則網址跑完，各欄位正確率目視檢查 ≥ 90%

### Phase 2：集團新聞抽取 `group_news.py`

- 從摘錄 .docx 用「第N則」取出對應文章
- 解析出 媒體 / 日期 / 記者 / 標題 / 內文
- **驗收**：`第1,3則` 能正確取出經濟日報與台灣時報網那兩則

### Phase 3：Word 產出 `build_docx.py`（核心，最花時間）

- 以前一天的成品當 template，**沿用其樣式定義**
- 核心函式 `add_news_block(doc, article)` 依 §4.2 規格產生一則
- 依 §2.1 的類別順序排列，每個類別開始前分頁
- 圖片抓失敗時，插入紅字段落 `【圖片待補：{url}】`
  （寧可讓失敗可見，也不要靜默跳過）
- **驗收**：產出檔用 Word 開啟，與前一天成品並排比對，
  表格框線、字級、圖片寬度、段距皆一致

### Phase 4：串接與收尾

- `main.py`：吃 .eml → 產出 `outputs/YYYYMMDD_每日新聞剪報.docx`
- 終端機印出摘要：成功 N 則、待補圖 M 則、失敗 K 則
- 補上首頁目錄頁碼（見 §4.3）
- 寫 `README.md` 交接文件：安裝、每日操作步驟、常見失敗排除

## 7. 硬性限制

1. **絕不自動寄信。** 產出草稿即停，由我校對後手動寄出。
2. **不要把任何內部檔案或信件上傳到外部服務。** 全流程本機執行，
   對外連線僅限公開新聞網站。信件標註「機密／內部限閱」。
3. **保留 `sleep(1.5)`。** 被對方封 IP 的代價遠大於省下的 40 秒。
4. **失敗要可見。** 任何抽取失敗都要在終端機列出，
   並在 Word 檔中以紅字標記位置，不得靜默略過。
5. 不引入需要架 server 的東西（n8n、Docker、排程服務）。
   單一 Python 專案，指令列執行即可。
6. 實習 8/21 結束 → **總開發時間預算約 2 個晚上**。
   遇到不確定要不要做的功能，先問我，不要自己擴張範圍。

## 8. 技術選型

```
python-docx      Word 讀寫
trafilatura      內文抽取（主力）
beautifulsoup4   og:image、fallback 選擇器
requests         HTTP
```

不要引入 Selenium / Playwright — 若真的需要瀏覽器，改用 Claude in Chrome
人工半自動處理那幾則。
